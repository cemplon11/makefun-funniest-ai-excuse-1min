One line, one minute: the funniest AI excuse. I spent 47 minutes confidently
hallucinating a shortcut, then asked myself for directions and got ghosted
by me. The program is pure-stdlib Python and writes that one line,
deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
